# Changelog · Red Blue CP 浏览器插件

> 插件（油猴脚本 + MV3 扩展，共用一套核心逻辑、共用版本号）独立于主程序 `rbcp` 计版。
> 跨工具契约是 **`schema_version`**（notes.json 格式）——当前 `1`，与 `rbcp` 的 `service/batch.py SUPPORTED_SCHEMA_VERSION` 必须一致，格式变了才一起 bump。

## 0.3.0 — 2026-06-07

### 新增
- **油猴脚本版**（`rbcp-xhs.user.js`）：通过 Tampermonkey 一键安装、自动更新（`@updateURL` 指向 GitHub raw），免去「加载已解压扩展」。页内右下角悬浮面板替代扩展 popup（显示条数 / 导出 / 复制 / 部分）。推荐普通用户用这个。
- MV3 扩展与油猴脚本共用同一核心，并入同一版本线。

### 变更
- 名称「小红书清单抓取」→「小红书清单导出」，描述中性化（去掉实现细节措辞），更贴近用户视角。

## 0.2.1 — 2026-06-07

### 修复
- 「半份/还没到底」措辞改为「导出部分」+ 说明：笔记少的博主首屏即全部、只是没有翻页信号无法自动确认是否到底，不再像出错。

## 0.2.0 — 2026-06-07

### 修复
- **笔记少的博主抓不到**：插件原来只拦翻页的 `user_posted` 网络请求，但博主主页第一屏笔记是服务端直出（藏在 `__INITIAL_STATE__.user.notes`，Vue ref，字段驼峰），不发请求。笔记少的博主一屏到底不触发翻页 → 一条没抓到。
- 改为优先从页面初始状态读取（app 自己的笔记仓库，不管首屏直出/翻页/换接口都在这里，比 hook 网络更稳）；字段两种命名都认（网络下划线 + 初始状态驼峰）。导出前补抓 + hydration 后自动补抓一次。

## 0.1.0 — 2026-06（M4 首版）

### 新增
- MV3 插件：在博主主页随滚动接住翻页响应，按 note_id 去重攒清单，滚到底（`has_more=false`）标记完整，点图标导出 `notes.json` 或复制到剪贴板。配合 `rbcp batch` 走代理批量下载。只抓清单，不下载正文、不上传。
