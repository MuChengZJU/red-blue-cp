# 0.6 · `rbcp digest --json` 输出契约（M6d/e/f fan-out 共享接缝）

> 这是 **CLI 产出 / Desktop 消费** 的唯一接缝。两个并行单元（M6f CLI、M6e+d Desktop）都按本契约开发。
> 真实样例见同目录 `0.6-digest-json-sample.json`（FakeProvider 生成，形状准确）。

## 顶层信封

```jsonc
{
  "extract": {                       // 来自 rbcp-extract（ExtractResult 的子集）
    "canonical_text": "原文…",       // canonical 原始原文 = 唯一锚定坐标系
    "text_sha256": "…",              // canonical_text 的指纹
    "segments": [                    // ASR 句级；图文为 null
      {"text":"…","speaker_id":"0","start_sec":0.0,"end_sec":3.2,"char_start":0,"char_end":11}
    ]
  },
  "digest": {                        // 来自 rbcp-digest（DigestResult）
    "highlights": [...], "cards": [...], "outline": [...],
    "model": "qwen-plus",
    "source_text_sha256": "…",       // 必须 == extract.text_sha256，否则坐标已漂、整份作废
    "coordinate_space": "python_codepoint",
    "normalization_version": "v1",
    "diagnostics": [...]             // 未锚定/低置信项，不渲染但可查
  }
}
```

## 三形态字段

- **highlight**：`{span_start, span_end, weight(0-1), source}`。`span_start/span_end` 是要在原文里高亮的区间。
  `weight` 用于排序 / "只看高亮"阈值。`source` 同区间 + `seconds`(视频时间戳，图文 null) + `anchoring_status` + `confidence`。
  **不变量**：`span_start==source.char_start && span_end==source.char_end`。
- **card**：`{quote, source|null}`。`source` 为 null = 该金句锚不回原文（LLM 自由生成），仍展示 quote、但不可跳转。
- **outline 节点**：`{title, source|null, children:[...递归]}`。`title` 可能是 LLM 自拟（非原文）；`source` 有则可跳转。
- **diagnostic**：`{kind(unanchored|low_confidence|ambiguous), quote, reason, confidence, suggested|null}`。调试/审计用，0.6 当不透明列表，UI 勿据具体字段做核心渲染。

## ⚠️ 坐标系：codepoint vs UTF-16（Desktop 渲染必读）

`span_start/span_end/char_start/char_end` 都是 **Python codepoint 下标**（`coordinate_space:"python_codepoint"`），
**不是** JS 的 UTF-16 码元下标。中文/标点（BMP）两者一致；但 emoji / 罕用字（astral，U+10000+）一个 codepoint = 2 个 UTF-16 码元，
直接用 JS `str.slice(span_start, span_end)` 会**错位**。

Desktop 渲染高亮**必须**按 codepoint 切：
```js
const cps = Array.from(canonicalText);          // 按 codepoint 拆
const piece = cps.slice(span_start, span_end).join("");  // 正确
// 不要用 canonicalText.slice(span_start, span_end)  // astral 字符会错位
```

## 单元职责（fan-out 边界）

- **M6f CLI（碰 app/cli.py + app/extract/facade.py + app/digest/ + tests/，不碰 desktop/）**：
  实现 `rbcp digest <url> [--json]`：extract(url)→digest(text, segments)→按本契约 `json.dumps(asdict)` 出 JSON。
  另含 `rbcp get/search/ls/config` + 门面动词。`--json` 输出必须能被本契约校验。
- **M6e+d Desktop（只碰 desktop/，不碰 app/）**：Tauri v2 壳 + PyInstaller sidecar（跑引擎），
  前端渲染三形态（高亮跳读 / 卡片金句 / 脉络），同屏、"一竖屏读懂"。开发期对着
  `0.6-digest-json-sample.json` 渲染；联调期 sidecar 走 `rbcp digest --json`（或 HTTP）。
  目标 eval：真实样本一竖屏抓住重点。
