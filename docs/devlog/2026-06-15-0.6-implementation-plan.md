## §C `rbcp-digest` 数据形状（M6c · Render/CLI 的消费契约，最关键的缝）

```python
@dataclass(frozen=True)
class SourceRef:               # 回原文出处（坐标系=canonical text 的 codepoint index）
    char_start: int | None = None  # 在 canonical text 的 codepoint 区间
    char_end: int | None = None
    seconds: float | None = None   # 由 char 区间映射到最近 segment 的时间戳
    image_index: int | None = None # 图文第几张
    anchoring_status: str = "exact"  # exact | normalized | unanchored
    confidence: float = 1.0          # 低置信不进高亮，只进 diagnostics

@dataclass(frozen=True)
class Highlight:
    span_start: int; span_end: int    # canonical text 的 codepoint 区间
    weight: float                     # 0-1，排序/"只看高亮"阈值
    source: SourceRef

@dataclass(frozen=True)
class Card:
    quote: str
    source: SourceRef | None = None

@dataclass(frozen=True)
class OutlineNode:
    title: str
    source: SourceRef | None = None
    children: tuple["OutlineNode", ...] = ()

@dataclass(frozen=True)
class DigestResult:
    highlights: tuple[Highlight, ...]
    cards: tuple[Card, ...]
    outline: tuple[OutlineNode, ...]
    model: str
    # 坐标系契约（Codex#4）：所有 span/SourceRef 针对的就是这份 text
    source_text_sha256: str            # 必须 == ExtractResult.text_sha256，否则坐标失效
    coordinate_space: str = "python_codepoint"   # 前端 UTF-16 需自行转换
    normalization_version: str = "v1"
    diagnostics: tuple = ()            # 未锚定/低置信的项，不渲染但可查

def digest(text: str, *, provider, text_sha256: str,
           segments: tuple[Segment, ...] | None = None) -> DigestResult: ...
    # 调 LLM 产出三形态。定位＝【确定性服务端锚定】，不是 LLM 报位置（见下）。
```

**锚定方案（eng + Codex#3/#4 定）**：
- LLM **不返字符 offset**（数不准），返回 `quote + context_before + context_after + 可选 segment_id`。
- 后端 **exact-first → normalized-second**（标点/空白归一）锚定，产出 `span + anchoring_status + confidence`；**低置信不进高亮，只进 `diagnostics`**（Codex#3：避免"多次出现全标"制造假高亮——靠 context 消歧定位唯一处）。
- **坐标系锁死**（Codex#4）：span 一律针对 `ExtractResult.text`（canonical 原文）的 **Python codepoint index**；`DigestResult.source_text_sha256` 必须等于 `ExtractResult.text_sha256` 才有效；前端 JS（UTF-16）用后端切好的 span 或转换函数，别自己按字符数定位。
- 时间戳＝由 `char` 区间落到覆盖它的 `segment.char_start/end` → 取其 `start_sec`。
- 锚定是确定性服务端步骤 → "可追溯"几乎免费，**砍 `with_trace` 开关，一直锚**。

**这是 Render（Desktop）和 CLI `digest` 共同消费的契约——锁死它，三形态 UI 和 `rbcp digest --json` 才能并行做。**

## Round 3 · 契约桩对抗审查（2026-06-16，落地为代码桩时）

把 §A/§B/§C 写成可执行桩（`app/extract/contracts.py` + `facade.py` + `app/digest/contracts.py` + `tests/test_contracts_0_6.py`）后，用 4 个独立 lens（plan-fidelity / 迁移可行性 / 坐标系锚定 / 隔离 lint）对抗审查。2 blocker + 4 major 全部在桩里修掉，**契约据此补强**（对 Round 2 锁定的细化，非推翻）：

1. **import-lint 相对 import 漏洞（blocker，已复现）**：原 lint 只看 `level==0` 的绝对 import，`from ..extract.model import X` 能 100% 绕过、运行时真能破隔离而测试仍绿。修：相对 import 按文件所属包解析成绝对再比对；`glob`→`rglob` 覆盖未来子包；加对称纪律 `extract 不许 import app.digest.*`；并单测 lint 本身能抓相对/绝对违规。
2. **digest 指纹防漂自校验（blocker）**：`digest(text, text_sha256)` 收原文+指纹两个可矛盾入参且无校验 → 防漂机制形同虚设。修：`text_sha256` 改可选的**调用方断言**，传了且 != `text_fingerprint(text)` 立即 `ValueError`（live，桩阶段就守）；`DigestResult.source_text_sha256` 规定一律 = `text_fingerprint(text)`，绝不照抄外部值。
3. **区间语义（major）**：全局锁死 char_start/char_end/span 一律**左闭右开 [start,end)**，Segment/Highlight/SourceRef 共用，杜绝 off-by-one。
4. **Highlight span↔source 绑定（major）**：两套 offset 冗余 → 加 `__post_init__` 自执行不变量 `span==source.char`，不一致拒绝构造。
5. **Segment 只索引 canonical（major）**：硬不变量写明 segment offset 只对 `ExtractResult.text`（canonical）、与 `readable_text` 无对齐；`text` 必须就是 `build_canonical_text_and_segments` 的产出，归一化在产指纹前完成。
6. **seconds 图文行为（major）**：图文（segments=None）`seconds` 恒 None、改用 image_index；视频映射规则（覆盖 char_start 的 segment / 缝隙取右侧 / 跨段取起点段）写进契约。
7. **细化**：指纹算法锁为 UTF-8+sha256（两侧统一 `text_fingerprint()`）；`diagnostics` 由 `tuple[Any]` 改 `Diagnostic` dataclass（0.6 provisional，UI 当不透明列表）；`BatchResult` 归位到 contracts；ExtractResult 一律 kwargs 构造、字段顺序非契约。

**迁移结论（供 M6b）**：`raw_info` 唯一消费者是 `markdown._result_suffix_id`，且它真正需要的 `post_id` 已在 metadata 里 → **不把 raw_info 加回冻结契约**，M6b 把该函数改读 metadata；`save_media` 读的是函数内 `info` dict 非 result，不受影响。`.md body 存 canonical 还是 readable` 升为**需用户拍板**（影响 0.5.x 存量知识库语义）。

**VERDICT R3**：契约桩 513 测试绿（含 14 个 0.6 契约/lint 守护测试），关键不变量自执行。§A/§B/§C 锁定，可 fan out。
