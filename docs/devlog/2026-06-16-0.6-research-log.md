# 0.6 规划期调研与评审过程日志

> 汇总 0.6 规划期的**事实调研**（带出处）+ **双轮评审过程**，供日后追溯。无隐私、无商业内容（商业决策走私有，不在此）。决策见 [speed-read-product](2026-06-15-0.6-speed-read-product.md)，接口契约见 [implementation-plan](2026-06-15-0.6-implementation-plan.md)。

## 过程概览

发散方向（不只做管道、转做"给人的速览"）→ 命名收敛（RBCP / Extract→Digest→Render / RBCP CLI / RBCP Desktop / 将来 Mobile）→ 写实现计划 + 三个接口契约 → `/plan-eng-review`（工程主管视角审架构与范围）→ Codex 独立审（专挑技术细节）→ 9 项决策锁定。命名消歧用 GitHub/`gh`/GitHub Desktop 的惯例（单说品牌名指整体，加平台后缀指具体面）。

## 事实调研（带出处）

1. **PR#46**：OPEN 草稿，外部贡献者，`+88/-0` 带回归测试。把 `RBCP_LLM_MODEL`/`RBCP_VLM_MODEL` 环境变量接进 provider（之前运行时只认 ASR 模型）。**未合并**，0.6 收尾合入。
2. **ASR 流程（读代码核实）**：无 ffmpeg。B站走 DASH 取独立音轨、小红书取整 MP4 → 本机带 Referer 流式拉（1MB 分块）转推进 DashScope OSS（内存中转不落盘）→ 异步任务轮询。**不能直连平台 CDN**（防盗链 + 链接过期）。句级时间戳在 payload（`sentences[]`）里但现仅读 text/speaker_id（model.py:565）。
3. **配置硬伤**：SPEC.md:53 教用户配 `~/.config/rbcp/.env`，代码裸 `load_dotenv()` 只读当前目录、从不读它 → 新用户首跑断。0.6 用 platformdirs 实现发现顺序修掉。
4. **Provider 泛化**：LLM 清洗 / VLM 图文已是 OpenAI 兼容 `chat/completions`，换端点近乎零成本；**ASR 是 DashScope 私有异步+OSS，才是泛化硬骨头**。
5. **GUI 技术**：Tauri v2（2.10.1）sidecar 模式可塞 PyInstaller 打包的 Python 服务（有生产级先例 dieharders/example-tauri-v2-python-server-sidecar）；Tauri 内存 30-50MB / 包 <10MB，Electron 150-300MB / 80-150MB。
6. **DeepSeek V4**（2026-04-24 发布）：Flash（1M 上下文、约 $0.14/$0.28 每百万 token）/ Pro（1.6T、1M 上下文）。OpenAI 兼容 → 引擎 provider 层填个 base_url 即可，不用专门适配。
7. **Ultra Code**（Opus 4.8 的 `/effort` 档，原名 workflow）：xhigh 思考 + 自动编排多个并行子 agent。最佳实践：**先锁接口再 fan out**、先在子集试跑设预算、看 token（N 个 agent 烧 N 倍）、大批并行用 fast mode、人工审计划 + 审 diff。已知坑：过度 spawn（anthropics/claude-code#66867）。Fable 5 因出口管制暂停（2026-06-13），默认回 Opus 4.8。
8. **竞品**：BibiGPT（商业 SaaS，30+ 平台含小红书，AI 总结=有损）/ BiliNote（开源，B站+YouTube，6.3k star，不做小红书图文）；间接 Readwise Reader / Glasp / NotebookLM（跨文档研究）。空位 = "短视频/图文 → 忠实原文 → 一屏速览、信息不丢"。
9. **知识库管理 Agent skill**：Obsidian MCP / claude-obsidian / Nooscope 等一大堆（读本地 Markdown 当第二大脑）→ 含义：输出侧 KB 管理已被生态解决，rbcp 当好"源"即可，工作台填"不想折腾 Agent 的人"那个缺口。
10. **AG-UI（CopilotKit）/ A2UI（谷歌）**：agent↔人富交互协议（流式事件 + 人工确认）。前端框架层，远期可能，0.x 不碰。

## 双轮评审净产出

- **Eng-review（架构/范围）**：分发物切包（PyPI=Extract+Digest+CLI 轻量无 GUI；RBCP Desktop=独立安装包，GUI 不上 PyPI）；`service/`→`extract/` 改名先行独立 commit；render+Desktop 壳合为一个并行单元（共用 `desktop/` 防撞）；Tauri+PyInstaller sidecar 先 spike。
- **Codex（技术细节，几个 eng 漏的）**：① 现 `text` 是 `llm_clean` 后的清洗版、与"忠实原文"+锚定冲突 → 决策 C：canonical 原文 + readable 两份都存；② Segment 缺 `char_start/char_end`，需原子产出 text+segments；③ 锚定升级（LLM 返原话+前后文、后端 exact→normalized + 置信度、低置信只进 diagnostics）；④ 坐标系锁死（codepoint index + sha256，防前端 UTF-16 漂移）；⑤ 模块路径留兼容 wrapper，不砸 0.5.2 用户。
- 互补：Codex 深在契约细节，eng 全在范围/分发。
