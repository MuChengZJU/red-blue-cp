# 0.6 方向：从「管道」调头做「给人的速览」产品

> 一句话：引擎仍开源，在其上加一个**给人快速读懂**的产品层。RBCP 从"把内容转成忠实原文的管道"演进为"忠实原文 + 速览阅读"。

## 背景与调头

0.5.2 把"B站/小红书 → 忠实原文 Markdown"的管道做稳了。dogfood 后发现两件事：(1) 转出来的原文**自己懒得逐字看**；(2) 丢给通用 AI 对话**有损、且没沉淀**。结论：管道已成立，缺的是**输出侧给人的消化层**。

这推翻了早先"只做开源管道层、不做产品"的取向——但**不推翻开源**：引擎照常开源，只是在上面加产品层。`exp/agent-interface-demo`（MCP 4 动词 demo）就此存档 `parked`：CLI 已覆盖 Agent 场景，MCP 出口降级为可选、暂搁置。

## 产品架构：一条 Pipeline，三段 + 两壳

- **品牌 = 产品 = RBCP**（整条 Pipeline 的概念名）。
- **Pipeline 三段**：
  - **Extract**（原 "Core"，开源库 `rbcp-extract`）：采集 + 转录 → **忠实原文**（无损，机器/AI 读；含存储/检索）。
  - **Digest**（开源库 `rbcp-digest`）：原文 → **高亮 / 卡片金句 / 脉络**（有损 LLM）。**与 Extract 隔离**，不污染"忠实原文"招牌。
  - **Render**：生成 / 渲染呈现。
- **两个壳**（能力不强求对等，有意）：
  - **RBCP CLI**（`rbcp` 命令）：自动化 / 批量 / 喂 Agent；给数据不给视觉。
  - **RBCP Desktop**（Tauri GUI）：给人；速览的视觉呈现。**原门控 P2 的桌面 GUI 在此正式启动。**
- **RBCP Cloud（私有）**：中心化托管后端 + 计费，单独私有仓库，**不在开源范围**。
- 将来 **RBCP Mobile**（触达 / 快速上传，连云）。
- **命名消歧**（交流/文档用，不印给用户）：单说 "RBCP" = 整个产品；指明哪个面用 RBCP CLI / RBCP Desktop / RBCP Mobile。参照 GitHub/`gh`/GitHub Desktop。

仓库：monorepo `red-blue-cp` 放 `rbcp-extract` + `rbcp-digest` + Render + RBCP Desktop + `rbcp` CLI；接缝＝内部 import、对外给 Agent 走 CLI（MCP 搁置）、Desktop↔Cloud 走 HTTP。

## RBCP Desktop · 速览（核心差异化）

- 三形态**同屏**：① 全文重点**高亮**（跳读，可"只看高亮"）② **卡片 / 金句** ③ **脉络**大纲。
- 目标：真实刷到的视频/图文，**一竖屏抓住重点、丢冗余**（这就是验收 eval）。
- 永远保留「原文」切换（忠实原文是护城河退路）。
- 保留**最小 Library**（历史/搜索/状态/原链接，现 WebUI 已有雏形）——不是知识库管理，是复访理由。
- **可追溯速览**（可选增强，不动三形态 UI）：每个高亮/金句/脉络点可跳回原文出处（段落/时间戳/图位置），有损可疑时一键核对、也实现"保留人工阅读"。

差异化定位：不是"笔记/总结/知识库"（那是 BibiGPT 的有损总结、Obsidian 的存管）；是 **快 + 忠实原文不丢**。空位＝"短视频/图文 → 忠实原文 → 一屏速览、信息不丢"。

## 节奏：已设计的并行干，没想清的串行

"一步一步来"重定义＝**已经设计透的可以一口气并行做**（接口锁死后 fan out，AI 多 agent 并行），**自己都没想清楚的才串行**（教训：exp 分支没对齐就开干 = 看不懂、用不了）。

- **0.6 并行批（已设计）**：配置清零（地基）· Extract 清接口 · Digest · 速览三形态 + Render · RBCP Desktop 壳 · RBCP CLI 整理。
- **串行往后（没设计透）**：RBCP Cloud 后端 · 计费 · RBCP Mobile · 精读/跨篇 · 可追溯速览。

## 取舍

- **砍**：本地模型 / 本地引擎（伪需求——爱折腾的人自己配阿里云百炼或本地 Whisper 即可，开源社区无此诉求）。
- **defer**：收藏夹自动同步（隐私死穴：平台收藏夹要公开可见才抓得到，但有些收藏不想公开）；知识库管理（另一个产品，且作者尚不熟，先做起来再说）。

## 调研支撑（2026-06 核实）

- 配置硬伤实锤：SPEC 教用户配 `~/.config/rbcp/.env`，代码裸 `load_dotenv()` 从不读它 → 新用户首跑断。0.6 用 platformdirs 实现发现顺序修掉。
- PR#46（OPEN 草稿）= 把 LLM/VLM 模型环境变量接进 provider，0.6 收尾合入。
- Tauri v2 sidecar 可塞 PyInstaller 打包的 Python 服务（有生产级先例）；Tauri 30-50MB vs Electron 150-300MB。
- ASR 现状＝DashScope 私有异步 + OSS 中转（防盗链导致不能直连平台 CDN）；LLM/VLM 已是 OpenAI 兼容，换端点近乎零成本，ASR 才是泛化硬骨头。
- 竞品：BibiGPT（商业有损总结）/ BiliNote（开源、不做小红书图文）/ Readwise/Glasp/NotebookLM（间接）。

## 商业（仅指针，细节走私有）

商业版＝托管 + 手机访问 + 配好模型 + 计费，走私有 RBCP Cloud，单独私有仓库，**定价/收款/计费细节不进开源文档**。
