# 0.6 桌面端实测连环修 + 四项补强 + v0.6.0 发布

## 背景

桌面端 0.6 一夜建成（见 [2026-06-17](2026-06-17-0.6-desktop-built-and-running.md)）后，用户真机连续试用，逐轮暴露问题。本日把桌面端从「能跑但糙」补到「对齐 WebUI、可发布」，并发 v0.6.0（首个速览产品版本）。

## 一、实测连环修（用户真机逐轮暴露）

> 教训母题仍是「完工 = 真链路跑通」，而且桌面端有一层额外陷阱：跑的是冻结二进制。

1. **无法转录 `llm_clean HTTP 400`** —— 根因不是网络/额度，是**设置页存空串**把 `RBCP_LLM_MODEL`/`VLM`/`OUTPUT_DIR` 清成 `""`。读侧普遍用 `os.getenv(k, default)`，而 **空串 ≠ 未设，默认值不生效** → `model=""` 发给 DashScope，原话 `"you must provide a model parameter."`。ASR 模型没被清所以转写能跑、卡在 llm_clean。同根因还解释了仓库里冒出的 `_index.sqlite`（`Path("")`→cwd）。修：读侧 `getenv(k) or default`（模型 + 新 `config.resolve_output_dir()` 替 9 处内联），写侧 `set_config` 空串跳过。
2. **桌面端跑的是冻结 PyInstaller sidecar** —— 改 Python 源码后光清 `.env` 不生效（旧二进制 + 用户再存一次设置又写空）。必须 `desktop/sidecar/build.sh` 重打 + 重启 app。**这是本轮最大的认知盲点**：桌面端调试要区分「前端改动（重载即可）」vs「后端改动（重打 sidecar）」。
3. **sidecar 漏打 `app/extract/templates`** —— `note.md.j2` 不在包里 → `TemplateNotFound`。`build.sh` 只 `--add-data` 了 `app/web/templates`。补上 extract 模板。
4. **导出 401「Not authenticated」+ 无退路** —— 导出是 `<a href>` 跳转，不带 Bearer token → 后端 401，且 webview 被导航到 401 JSON 页、没有浏览器后退键 = 卡死。改为带 token fetch 成 blob 再触发保存，不导航。
5. **外部 API 报错不可见** —— `format_error_for_user` 把 `payload_excerpt` 剥掉，只进服务器日志，GUI 看不到（用户说的「没日志」）。`_safe_error_detail` 把服务商 JSON 报错体带进失败详情（不含本机路径，安全）。

## 二、四项对齐 WebUI 的补强（understand → implement → review 三段 workflow 编排）

用户的隐含标杆是 WebUI——桌面端是另起炉灶的精简 SPA，和 WebUI 双份漂移，所有「不如 WebUI」的吐槽本质是这个分裂。盘点后发现**桌面端其实是超集**（多了文件库/设置/速览三形态/独立账单），方向是「补齐 + 抛光」而非「切回 WebUI」。

1. **任务状态筛选 chip**（全部/处理中/完成/失败 + 计数，纳入防闪烁 signature）。
2. **整篇连贯阅读视图**（reader 第④视图，marked + DOMPurify 懒加载渲染 .md；早期转录回退也复用同一渲染，不再露 `#`/`>` 源码）。
3. **文件库封面缩略图**（后端捕获 B站封面/小红书首图 → `/api/jobs/{id}/thumbnail` 缓存端点，红线#5 不进知识库、#11 防盗链、无新依赖；前端带 token 取 blob、并发去重、删除时释放 objectURL）。
4. **抛光**：输入区 `<form>`+回车+实时平台检测+防重复提交、加载 spinner、空态卡片、批次卡片进度+费用、账单可排序表格、补一批漏定义的 CSS（`.placeholder`/compose 表单/状态提示）。

**渐进加载**：reader 打开调 `/digest` 会**当场同步跑 LLM** 才返回，整个阅读器空等「加载中」。改成先并行取 `.md` 全文顶上（350ms 内 digest 没回来才显示，避免缓存命中闪烁），速览算完再整体替换。

**桌面 app 图标**：用 WebUI 的两方块红蓝 logo（`rsvg-convert` → 1024 PNG → `cargo tauri icon` 全套）。

对抗审查（understand workflow 4 路并行调研 → implement → review workflow 5 维度 × 逐条对抗验证）共确认并修 16 项：批次/筛选可见性同步、markdown 加载竞态、缩略图并发去重+内存释放、缺 CSS、防重复提交、内联 onclick 改事件委托等。

## 可复用 lesson

- `getenv(k, default)` 配「能存空串的设置 UI」是反复踩的雷——空串当默认处理（读 `or`、写 skip）。
- 桌面端 = 前端（Tauri webview 加载 frontendDist，重载生效）+ 后端（冻结 sidecar，改源码必须重打）。调试先分清改的是哪层。
- 双前端（WebUI + 桌面）会漂移；与其逐点补，不如认清谁是超集、往一个方向收敛 + 抛光。
- 外部 API 报错体必须可见（至少进失败详情），否则「没日志」无从排查。
